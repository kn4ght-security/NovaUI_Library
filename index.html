NovaUI
Install Features Disclaimer

A UI library for Roblox scripts

Windows, tabs, sliders, dropdowns, keybinds, saved configs and a loading screen. Made to work on mobile and desktop.

Load it

Run this in your executor to load the library:

local NovaUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/kn4ght-security/NovaUI_Library/refs/heads/main/NovaUI_Library.lua"))()

local window = NovaUI:CreateWindow({ Title = "My Hub" })
local main = window:CreateTab("Main")
main:Button({ Name = "Hello", Callback = function() print("hi") end })

A full example with every element is in the GitHub repository.

What is in it

  • Toggles, sliders, buttons, dropdowns (multi select and search), textboxes, keybinds and color pickers
  • Config manager: create, load, overwrite, delete and auto load
  • Loading screen with a PNG image
  • Profile tab with the player's avatar
  • Notifications, dialogs and a code box
